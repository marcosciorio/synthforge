# MIDI mapping between SynthForge and TAL-NoiseMaker

SynthForge sends each of the 63 generated parameters to TAL-NoiseMaker as a MIDI control-change (CC) message on channel 1, with CC numbers between 20 and 89. TAL-NoiseMaker must map each CC number to the corresponding control.

## Recommended setup: a preset with the mapping already set

The `<midimap>` tag of a `.noisemakerpreset` file stores the MIDI-learn mappings, so the whole mapping can be written by a script:

```
python3 generate_midi_setup_preset.py
```

The script writes `SynthForge_MIDI_Setup.noisemakerpreset` and copies it into the TAL-NoiseMaker preset folder. To apply it:

1. Open TAL-NoiseMaker, as a standalone application or inside the DAW.
2. Load the preset "SynthForge MIDI Setup" from the preset browser, or drag the file onto the plugin window.
3. Check a few controls, for example CC 39 for the filter cutoff and CC 20 for the waveform of oscillator 1. `send_test_cc.py` sends test messages on a virtual MIDI port.

## Manual setup

For each row of the table, right-click the control in TAL-NoiseMaker, choose "MIDI Learn" and send the corresponding CC number on channel 1. The mapping is stored with the DAW project.
